# 📝 Notesboard

Notesboard is a simple and user-friendly note-taking web application built with **React**. It allows users to create, view, and manage notes efficiently through a clean and intuitive interface.

This project is designed to strengthen understanding of **React fundamentals**, **routing**, and basic **CRUD-style workflows**.

---

## 🚀 Features

* Create new notes
* View all notes on the home page
* View individual note details
* Simple and clean UI
* Client-side routing using React Router

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Routing:** React Router DOM
* **Styling:** CSS
* **Version Control:** Git & GitHub

---

## ⚙️ Installation & Setup

1. Clone the repository

   ```
   git clone https://github.com/your-username/notesboard.git
   ```

2. Navigate to the project directory

   ```
   cd notesboard
   ```

3. Install dependencies

   ```
   npm install
   ```

4. Run the development server

   ```
   npm run dev
   ```
